# Product

## Register

product

## Users

SolBreach is used by developers and security learners who already understand Rust, Anchor, Solana accounts, PDAs, token accounts, and the SVM at a working level. They are not absolute beginners, but they still need help connecting vulnerable account relationships to protocol impact.

## Product Purpose

SolBreach teaches Solana protocol exploitation through interactive research labs. Success means a learner can inspect vulnerable protocol logic, execute a constrained exploit, verify state impact, and produce a credible audit-style report that names the root cause, evidence, impact, and mitigation.

## Brand Personality

Precise, technical, restrained. The UI should feel like an auditor workstation: dense enough for real analysis, clear enough to guide learning, and confident without gamified clutter.

## Anti-references

Avoid generic CTF dashboards, oversized marketing cards, decorative cyberpunk panels, quiz-app patterns, and tutorial copy that explains concepts an Anchor/SVM-literate user can infer from the evidence. Avoid making the report flow feel like generated text pasted under a form.

## Design Principles

1. Show protocol state and account relationships before explanation.
2. Let canonical controls carry the learning flow: inspect, exploit, verify, report.
3. Reduce surface area after the learner proves understanding.
4. Use audit vocabulary directly: account constraints, approved mint, canonical vault, credit, treasury impact.
5. Preserve deterministic evaluation while making the final output feel like a real security deliverable.

## Accessibility & Inclusion

Target WCAG AA for contrast, focus states, keyboard navigation, and form labels. Keep motion functional and respect reduced-motion preferences. Use concise copy and stable controls so the dense technical UI remains scannable.
