# SolBreach learner workspace

Levels 0–3 contain unfinished JavaScript templates with hints. Install dependencies
with `npm ci`, inspect the corresponding Anchor source, and implement your own
transaction in `buildAttempt()`. Use devnet and a test wallet.

The public one-command solver and operator forwarding scripts were removed on
2026-10-12. The maintainer retained a local copy outside the public repository.
LiteSVM regression tests remain available under `anchor/programs/vault/src/tests.rs`
to verify solvability and authorization rules.

Removing entrypoints does not erase old Git history or make an open-source challenge
solution secret. A completion certificate records completion; it is not proof of
unaided work or professional auditing ability.
